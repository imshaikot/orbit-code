# Getting help

- **Installing and updating:** the [install guide](https://orbit-code.imshaikot.com/install/) on [orbit-code.imshaikot.com](https://orbit-code.imshaikot.com), which also publishes the docs and the changelog.
- **Using Orbit:** the [extension's README](apps/vscode/README.md), the [desktop app's README](apps/desktop/README.md), and [Using Orbit](docs/using-orbit.md) cover reading the view, navigating it, prompting Claude, and the settings.
- **Something doesn't work:** [Troubleshooting](docs/troubleshooting.md) says where the log is, and covers the failures with a known cause, such as "agent unavailable", a missing import or a frozen scene. **Orbit Code: Reindex Workspace** fixes most stale graphs.
- **A question the docs don't answer:** open an issue with the [Question form](https://github.com/imshaikot/orbit-code/issues/new?template=question.yml).
- **A bug:** use the [Bug report form](https://github.com/imshaikot/orbit-code/issues/new?template=bug_report.yml), with the Orbit log attached.
- **Imports missing or wrong for your language:** use the [Missing or wrong imports form](https://github.com/imshaikot/orbit-code/issues/new?template=imports.yml).
- **Claude Code itself** (installing, logging in, models, its answers): see [Claude Code's documentation](https://docs.claude.com/en/docs/claude-code) and [its issues](https://github.com/anthropics/claude-code/issues).
- **A security problem:** follow [SECURITY.md](SECURITY.md), not the issue tracker.

Orbit Code has one maintainer, so replies can take a few days.
